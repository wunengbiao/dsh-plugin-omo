# dsh-plugin-omo - distribution repository

**Package:** `dsh-plugin-omo` ｜ **Runtime:** plain Node ESM inside DeepSeek Harness ｜ **Source of truth:**
`packages/omo-dsh` in [oh-my-openagent](https://github.com/code-yeongyu/oh-my-openagent)

## WHAT THIS REPOSITORY IS

The installable distribution of the DSH adapter. It carries the built JavaScript the harness loads, the 18 staged
skills, and the bundle patch that inserts the `omo` row. Authoring happens in the omo monorepo; this repository is
what `dsh plugin add github:wunengbiao/dsh-plugin-omo` resolves to.

## GENERATED VS AUTHORED

| Path | Status |
|---|---|
| `index.js`, `lib/*.js` | Generated by `bun scripts/build.mjs` from `src/`. Committed so installs run no build. |
| `src/*.ts` | Mirror of `packages/omo-dsh/src` (minus tests). Edit there, then copy. |
| `skills/` | Mirror of `packages/omo-dsh/skills`, itself staged from `packages/shared-skills/skills`. Contains `manifest.json` with a sha256 per file. |
| `package.json`, `cordis.patch.yml`, `icon.svg`, `README*`, `CHANGELOG.md` | Authored here and in the omo package; keep them in step. |
| `test/plugin.test.mjs` | Authored here. Runs against the built entry with plain `node --test`. |

## INVARIANTS

- **Never hand-edit `index.js` or `lib/`.** Regenerate with `bun run build`, which transpiles `src/`, rewrites the
  `.ts` import specifiers to `.js`, and rebuilds the root entry.
- **Never hand-edit `skills/`.** They come from oh-my-openagent. `skills/manifest.json` records the sha256 of every
  file; a changed body without a regenerated manifest is a bug.
- **The installed package must run with zero dependencies and zero build steps.** `files` ships only the entry,
  `lib`, `skills`, the patch, the icon, and the docs. No `prepare` script: a git install must never execute code.
- **Loading never parses skill documents.** `apply()` only counts documents, so one malformed SKILL.md cannot fail
  the bundle. Discovery reports it: `list()` returns the surviving candidates with `complete: false`, `get()`
  reports that skill as unavailable, and the plugin logs the path.
- **Rank stays at 600.** Project roots (100, 200) and user roots (400, 500) must win duplicate skill names.
- **Fail loud.** Malformed SKILL.md, unknown config keys, wrong types, and the reserved `runtime` provider name all
  throw with a message naming the offending file or key.

## VERIFY BEFORE PUSHING

```sh
npm run check            # syntax of the committed runtime modules
npm test                 # 6 node --test cases over the built entry
bun run build && git diff --exit-code index.js lib/   # the committed JS matches src/
```

Real-surface check: `dsh plugin --profile web add github:wunengbiao/dsh-plugin-omo#<tag>` in an isolated
`DSH_HOME`, confirm the `dsh-plugin-omo` layer in `dsh --profile web --dump-config`, then mount the installed
`index.js` against the harness's own `@deepseek-ai/dsh-skill` `SkillRegistry` and assert `snapshot()` reports 18
skills with `provider: "omo"`.
