# Changelog

## 0.1.0

- First release: registers the `omo` SkillProvider in DeepSeek Harness and ships the 19 cross-harness omo skills.
- Configuration for `providerName`, `skillDir`, `extraSkillDirs`, `disabled`, and `rank`.
- Runtime modules are committed, so `dsh plugin add github:wunengbiao/dsh-plugin-omo#v0.1.0` installs without a
  build step or a pnpm build allowance.
